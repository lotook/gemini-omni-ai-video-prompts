# Gemini Omni AI Video prompt notes

Built around Gemini Omni 1.1 Flash, this experience turns text or a reference image into a 4–10 second clip.
Create 720p video with synchronized audio from a written prompt or visual starting point.
Use conversation to refine a shot, adjust camera direction, or change the lighting.
